Tahapan ini dimulai dair proses build yang membungkus project aplikasi kita menjadi berkas yang bisa dieksekusi pada masing-masing platform, misalnnya format:
- APK (Android Application Package) atau AAB (Android App Bundle) untuk Android
- IPA (IOS App Store Package) untuk IOS.

Jika Anda belum memahami berkas APK atau IPA, Anda dapat menyamakanya dengan berkas EXE (Executable) pada sistem operasi Windows
